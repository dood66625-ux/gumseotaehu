# 금서태후 (禁書太后)

**[금서태후 Royal v2 · 가상 정보로 둘러보기](https://dood66625-ux.github.io/gumseotaehu/?v=royal-10)**

GitHub Pages는 계정 소유자가 활성화했습니다. 공개 주소는 고정된 합성 데이터로 체험하는 별도 정적 버전이며 실제 운영 서버와 관리자 기능은 공개하지 않습니다.

준비한 미리보기는 사용자가 별도로 승인한 **정적 체험판**입니다. 고정된 가상 출생정보·이메일만 사용하며 입력 필드는 수정할 수 없습니다. 모의 구매·PDF·재열람·문의 화면을 브라우저 안에서 체험합니다. 운영 Next.js 서버나 실제 관리자·AI·PG·메일이 연결된 주소가 아닙니다.

한국어 모바일 중심 사주 운명서 서비스의 **독립 Next.js + TypeScript 로컬 검증판**. ChatGPT Sites·사이트 빌더를 사용하지 않는다. **상용 출시 준비 완료가 아니다.** 고객용 실제 AI·Toss·메일 미연결, 만세력 독립 검증/법률 검토/운영 인프라 미완료로 출시를 차단한다.

## 실행

Node.js 24.22 이상 권장 (내장 `node:sqlite` 사용).

```sh
npm ci
npm run setup
npm run dev
# 다른 터미널, 같은 프로젝트 디렉터리
npm run worker
```

`http://localhost:3000` 방문. 합성 데이터만 입력: 별명 가온 / 양력 1995-05-15 / 10:30 / 대한민국 / 이용자 만 19세 이상. 구매 이메일은 `tester@example.invalid` 등 예약 도메인을 사용한다. 인증 화면의 **로컬 시험 수신함 열기**로 코드를 확인한다. 실제 이메일 소유 인증이 아니므로 공개 배포하면 안 된다.

운영자: `/admin`. `npm run setup`이 생성한 `.env.local`의 `ADMIN_PASSWORD`를 로컬에서 확인하고 `npm run admin:code`의 현재 1회용 코드를 입력한다. 비밀번호/키를 Git·대화·로그에 올리지 않는다. 운영 환경의 사용자별 계정·역할·MFA 등록/복구 기능은 추가 구현이 필요하다.

```sh
npm run typecheck
npm test
npm run build
npx playwright install --with-deps chromium webkit
npm run test:e2e
npm run start
npm run backup
```

`npm run test:e2e`는 3000번 포트에서 별도 테스트 DB와 워커를 시작한다. 먼저 실행 중인 앱을 종료한다. 브라우저 의존성 설치가 불가능한 환경의 대응은 `docs/runbook.md` 참조. `npm run start`는 로컬 운영 빌드 검증용이며 호스팅 배포를 수행하지 않는다. Node 24의 SQLite 실험 경고가 발생할 수 있다.

## 안전 경계

`APP_MODE=local`, `EXTERNAL_EFFECTS=disabled` 외 설정은 서버에서 거부한다. 외부 전송 transport 기본값은 오류를 발생시킨다. 라이브 키를 넣어도 운영 결제가 활성화되지 않는다. 원문 개인정보/계산/보고서를 URL·광고·분석 로그에 넣지 않는다. 출생정보는 localStorage에 저장하지 않는다.

소스/마이그레이션/lockfile·폰트·테스트·문서를 포함하며 도메인·호스팅 업체에 종속되지 않는다. SQLite 원장과 암호화 키를 별도로 보존하고 워커를 함께 이전해야 한다. `.env.local`과 `var/`는 Git·배포 이미지·소스 압축본에서 제외한다.

## 랜딩 변경

`/`는 `app/route.ts`가 빌드 시 생성한 정적 HTML을 제공합니다. React 서버 JSX로 공통 Shell과 Landing을 렌더링하며 브라우저에는 React 런타임을 보내지 않습니다. `npm run landing` 또는 `npm run build`로 생성합니다. 개발 중 랜딩/CSS를 바꾸면 `npm run landing`을 다시 실행하세요. 선택적 `/intro.js`는 로딩 후 최대5초 텍스트만 전환하며 시작 링크는 JS 없이 동작합니다. 입력·결제·보고서 등은 일반 Next.js App Router입니다.

## 승인된 정적 미리보기

외부 연결 중계가 차단된 개발 환경을 대신해 `gh-pages` 브랜치에 가상 정보 전용 미리보기 산출물을 올렸습니다. Pages 활성화는 계정 소유자가 완료했습니다. 실제 서비스 소스는 main에 유지합니다. 미리보기는 기존 화면 컴포넌트를 별도 번들로 빌드하고 `/api` 호출을 브라우저 내부의 합성 어댑터로 처리합니다. 생년월일·이메일·이름·문의 내용은 가상값 고정, 관리자 기능 제외, 서버/외부 API 전송 없음. 전송된 정적 자산과 가상 보고서는 공개 자료입니다. sessionStorage에는 가상 체험 진행 상태만 보관합니다.

재현: `npm run build:preview` → 다른 터미널에서 `npm run preview:serve` → `npm run test:preview`. 원래 Next.js 로컬 실행·운영 아키텍처는 변경하지 않습니다. 운영 서비스 배포/실제 고객 데이터 처리 승인은 여전히 받지 않았습니다. 미리보기는 정식 출시 전 중단하거나 교체할 수 있습니다.

## 운영 보강
고객/관리자 세션 교체·중요 업무 최근 인증·TOTP 재사용 차단·작업 누락 복구·환불 원장 대조·이메일 변경·삭제 이력 복구·오프라인 DATA_KEY 교체를 추가했습니다. [검증과 남은 구현](docs/hardening-release.md), [현재 출시 차단 점검](lib/readiness.ts). 실제 외부 연결과 운영 공개는 비활성입니다.

토스 주문 통합 코어의 결제/환불 재조회·동시 요청·알림 처리·삭제 경합 검증: [구현과 검증 범위](docs/toss-order-integration.md). 실제 결제 경로 활성화는 수행하지 않았습니다.

메일 발송 큐·반송·재시도·복구 보류 코어를 가짜 공급자로 검증했습니다. 실제 공급자/worker는 미연결이며 소유 인증·실메일 발송 검증 완료를 뜻하지 않습니다. [범위 및 남은 조건](docs/mail-delivery-integration.md).

## 실제 AI 연결 보강

OpenAI 키는 비공개 설정에만 저장했다. 고정 가상 정보 전용 Responses HTTP 어댑터·전체 3회 호출 제한·비동기 보고서 저장의 임대/주문 재검증을 추가했다. 실제 생성 시도 1회는 HTTP 429로 막혀 중단했으며, 성공한 AI 운명서가 제공된 상태는 아니다. 앱/일반 worker/공개 체험판은 mock을 유지한다. [구현·실행 결과·한도 확인 후 재개](docs/openai-integration.md). `npm run check:secrets`는 OpenAI 키도 소스와 브라우저 자산에서 검사한다.

토스의 서명 원문 수신·발송 시각/중복 검사와 승인 누락 복구 연결을 추가했다. `/api/toss/webhook`는 기본 503이며 실제 결제나 외부 조회를 활성화하지 않는다. [새 테스트 수신 경로와 실제 상점 검증의 구분](docs/toss-signed-webhook.md).

## 신규 판매가 22,000원
운영자 지시로 새 주문/화면/약관/모의 결제/메일/합성 체험판 가격을 변경했다. 과거 33,000원 주문은 원래 금액과 보고서를 보존하고 전액 환불도 원 주문금액을 검증한다. [이전/검증 내역](docs/price-22000-release.md). 실제 판매 활성화 승인은 별개다.


## 토스 결제위젯 격리 시험
`npm run toss:sandbox -- --test-network`는 가상 주문 전용 서버를 `127.0.0.1:3211`에서 시작한다. 공개 앱의 결제 경로는 변경하지 않는다. 실제 SDK/결제수단 로딩·운영자 제공 MID 저장·테스트 카드사 인증 화면 진입/취소를 확인했다. 실제 인증 완료·승인·취소는 운영자의 결제수단 직접 인증 후 검증해야 한다. `npm run test:toss-browser`는 공급자를 모두 모의 처리한 모바일 Chromium·WebKit·데스크톱 Chromium 계약 검증이다. [실행·보안 경계·남은 항목](docs/toss-sandbox.md).


## 서버 이전용 로컬 패키지
로컬 Compose, 최소 runtime 패키징, web/worker 상태 probe를 추가했다. 오프라인 이미지로 가상 구매·PDF·재시작 후 상태/원문 유지·권한을 실제 검증했다. 소스 Docker clean build는 현재 컨테이너 npm 네트워크 제한으로 미검증이다. [실행 및 검증 범위](docs/local-runtime.md). 공개 호스팅이나 실서비스 배포는 하지 않았다.
