# 한글 글꼴·이메일 접수·대표 타입 (2026-11-27)

장식용 부분 글꼴 대신 기존 Noto Sans KR에서 추출한 일반/굵은 WOFF2를 사용한다. 두 글꼴 모두 한글 완성형 11,172자를 포함하며, 일반 약638KB·굵은 약658KB다. 영문·숫자·한글 자모·문장부호와 화면에서 사용하는 주요 한자도 포함한다. 브라우저에서 글자별 시스템 글꼴 대체가 생기지 않도록 본문·제목의 같은 글꼴 계열을 웹·비공개 리더에 적용했다. PDF는 기존의 전체 한글 Noto Sans KR를 계속 사용한다. 로고는 이미지다.

고객 화면의 문의/환불/이용 안내 링크와 버튼을 제거하고, 하단 환불 정책에서 이메일로 접수한다. 메일 제목과 구매 이메일/주문번호 또는 결제일/사유 양식을 채운 mailto 링크와 직접 복사할 이메일 주소를 제공한다. 기존 /help는 /legal/refund로 이동한다. 환불 조건·처리 기한과 관리자 처리 기능, 기존 접수 기록은 보존한다. 메일을 자동 발송하거나 환불을 실행하지 않는다.

대표 타입은 권력형·과학자형·사업가형·분석가형·발명가형·창작가형·전략가형·지도자형·개척자형·도전가형 중 하나다. 기존 사주의 십신 표시를 월간3/연간1/시간2로 살피며, 같은 점수에서는 기존 오행을 보조 단서로 쓴다. 정보가 없으면 기존 오행의 상징을 사용한다. 이름·성별·해시·무작위 값이나 추가 AI 호출로 타입을 바꾸지 않는다. MBTI 측정 결과가 아닌 금서태후의 이야기형 캐릭터 분류로 표시한다.

무료 풀이 첫 화면·구매 운명서·비공개 리더·PDF 표지에 같은 타입을 보여준다. 친구에게 보여주기 버튼은 기기 공유창 또는 클립보드를 사용하며 타입 소개와 일반 홈페이지 주소만 포함한다. 생년월일·이메일·주문번호·비공개 링크는 공유하지 않는다. 실제 타인에게 메시지를 보내는 검증은 하지 않는다.

검증: 전체 단위 테스트846개 통과, 일반/굵은 글꼴의 한글 전수 검사, 10종의 고정 분류·누락 시간·공유 정보 최소화·이메일 접수 경로 검사. Chromium/WebKit에서 글꼴 실제 로딩·타입 공유 데이터·본문 팝업을 확인했다. 무료 페이지와 결제 화면은390×664,320×568,1440×900에서 레이아웃을 확인했다. 실제 결제·환불·메일·AI 호출은 실행하지 않았다.

실제 도메인 확인: /legal/refund의 이메일 접수 버튼, /help의 정책 페이지 이동, 대표 타입 공유 UI, 한글 일반 글꼴 파일(637,976바이트) 제공을 확인했다. 추가로 모바일 Chromium/WebKit·데스크톱에서 이메일 접수 전환9개 브라우저 검증을 통과했고, 기존 전체 가상 구매/운명서/PDF/재열람 미리보기 흐름도 외부 API 요청0회로 통과했다.
