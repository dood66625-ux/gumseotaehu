# 고객 화면 내부 문구 정리 · 2026-11-28 KST

사용자 요청에 따라 실제 판매 화면의 관리자용 운영 메모를 정리했다.

- 주문 작성 지연/실패는 고객이 취할 수 있는 확인·문의 안내로 표시한다. 비용 예약·자동 재호출 등의 내부 설명은 표시하지 않는다.
- 결제 상태는 한글로 표시하고, 알 수 없는 상태는 확인 필요로 표시한다. 결제/환불 완료 여부와 열람 권한 판정은 변경하지 않는다.
- 운명서 버전 번호와 사업자 정보의 출시 전 준비 메모를 제거한다. 실제 상품·개인정보·AI 전송·환불 고지는 유지한다.
- 재열람·이메일 변경의 체험 인증번호 버튼은 서버가 명시적으로 체험 메일 환경이라고 알려준 경우만 표시한다. 실제 메일 작업 모드가 활성화되면 표시하지 않는다. 기존 서버의 시험용 인증번호 API 접근 차단은 유지한다.
- 고객 API 오류의 내부 영문 코드에는 일반 안내를 표시하고 HTTP 상태를 유지한다. 보호된 관리자 요청의 진단 코드는 유지한다.
- 실제 모의 주문은 모의 표시를 유지한다. 관리자 메뉴 링크는 고객 메뉴에 추가하지 않는다.

검증: 상용 빌드 및 비밀값 검사 통과. 관련 단위 검사29건 통과. 아이폰 WebKit·안드로이드 Chromium·PC Chromium의 인증/이메일 변경/주문 권한/환불 안내 브라우저 검사42건 통과. 실제 결제·메일·AI 공급자 호출 없이 합성 응답으로 검증했다. 운영 키/모델/비용 한도/결제·환불 기능은 변경하지 않는다. 전체 출시 진행표 수량은 유지한다.
