# 사주별 작성 연출 대사 · 2026-11-28 KST

일간10종의 자연물 비유와 어조, 이미 계산된 오행 글자 수의 관찰을 세 장면에 연결했다. 갑목은 큰 나무/굳센 기운, 정화는 작은 등불/온기 어린 기운처럼 달라진다. 최다 오행이 같으면 한 오행을 임의로 고르지 않고 어우러짐을 말한다. 단순 오행 개수를 신강·신약·길흉이나 미래 사건으로 단정하지 않는다. 사주 정보가 없거나 읽을 수 없으면 일반 사주 안내로 대체한다.

기존 인증된 단건 주문 조회에서 본인 소유·유효한 결제·미삭제·열람기간을 확인한 뒤 저장된 계산 결과를 읽는다. 응답에는 대사 세 문장만 추가하고 원본 생년월일·이름·전체 차트를 추가하지 않는다. 목록 조회와 관리자 조회는 변경하지 않는다. 새 AI 요청·작업·메일·비용은 없다. 권한이 없거나 환불/삭제/만료된 주문에는 개인화 대사를 반환하지 않는다. 부가 대사 복호화 실패가 주문 상태 확인을 막지 않는다.

앞 연출과 태극 화면에 같은 대사를 쓰며 대기 화면에서는6초마다 순환한다. 회수/삭제/만료 등 실제 주문 상태가 바뀌면 기존 상태 화면으로 전환한다. 장면당4초(총12초) 연출·SKIP·완성 즉시 연출 중단/완료 팝업·단일 폴링·금색 후광과4초 확대 주기는 유지한다.

`/preview/unsealing?day=갑`과 `?day=정`은 가상 계산 예시다. 실제 고객 정보나 AI API를 사용하지 않으며 검색 색인을 차단한다. 대기 화면만 보려면 `stage=wait`를 함께 지정한다.
