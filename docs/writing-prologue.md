# 운명서 작성 전 연출 · 2026-11-28 KST

금색·검은색 태극의 30% 확대 범위는 유지하고 주기를3.2초에서4초로 바꿔 움직임 속도를20% 낮췄다. 금색 테두리를 따라 은은한 빛이8초 주기로 회전한다. 동작 줄이기 환경에서는 움직임을 중단한다.

작성 상태 화면에 기존 초상/스토리 자산으로18초, 세 장면(장면당6초)의 짧은 연출을 추가했다. 오른쪽 아래 SKIP으로 즉시 대기 화면으로 넘어간다. 이미지가 먼저 나타나고 자막은0.7초 뒤 나타난다. 실제 주문 조회는 연출 중에도 기존 단일 폴링을 유지하며, 생성 요청이나 비용을 추가하지 않는다. 연출 중 작성이 끝나면 남은 장면을 즉시 중단하고 기존 완료 팝업을 표시한다. 처음부터 완성된 주문에는 연출을 재생하지 않는다. 주문별 재생 완료 여부는 현재 탭의 sessionStorage에만 기록하며, 본문/출생정보는 저장하지 않는다.

미리보기: `/preview/unsealing`은 세 장면부터, `/preview/unsealing?stage=wait`는 태극부터 표시한다. 미리보기는 API 요청이 없다.
