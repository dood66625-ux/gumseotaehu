# AI 및 콘텐츠 정책

현재 `local-rule-mock`만 동작하며 **실제 AI API는 미구현**. API 키/실 모델/유료 호출/토큰 비용 없음. lib/integrations/ai-contract.ts에 Responses 요청/Strict JSON Schema/응답 검증의 오프라인 계약을 추가했으나 워커에 실 API는 연결하지 않았다. 외부 transport 기본값은 거부하며 비용 미확정값은 null이다. 무료와 보고서는 같은 차트·claimIds에서 생성하며 저장값을 재열람한다. 9개 장 스키마와 근거 whitelist, 원본 차트 불변/금지문구 검사를 수행한다. 장별 정합성의 완전한 의미 검증이나 상용 콘텐츠 품질 검증은 아니다.

실 API 연결시: Responses + Structured Outputs, store:false, 고정된 prompt/model/rules 버전, 가명·계산된 사실만 전송. 날짜/이메일 원문을 기본 프롬프트에서 제외한다. 공식 API/계약의 보관·국외이전 조건을 검토한다. 스키마 성공과 사실 정확성은 별도다. 출력 간지/일간/수치와 인용 사실 검증, 단정적 사망·중병·불안/열등감·투자 성공·외도 예언 금지, 전문가 샘플 검수를 추가해야 한다.

향후 시스템 프롬프트 원칙: 금서태후는 창작 캐릭터, 품위 있는 옛말투, 따뜻하고 선택권을 존중. 실제 근거를 먼저 설명하고 다음 시기 흐름으로 연결. 전원 희귀 사주/허위 제한·판매 수/불안 유도 금지. 무작위로 계산을 바꾸거나 재열람시 다시 생성하지 않음.

워커: 60초 lease, 최대4회 시도, 지수 backoff(최대60초), 최종 실패 시 audit alert+로컬 안내, 관리자 재시도/환불. 실 API timeout/circuit breaker·일별 비용 상한·토큰 제한·사용량 계량은 실제 어댑터 구현 시 필수이며 현재 미구현.

Royal v2: 규칙 기반 예시문장 버전 taehou-2. 장별 중복을 줄이고 일상 적용 문장/월별 계획 제안을 추가했다. 미래사건 예언으로 표시하지 않으며,계산 스냅샷은 변경하지 않는다. 기존 저장 보고서는 재생성하지 않는다. AI 생성 초상과 텍스트 생성 방식의 고지는 별도로 유지한다.
