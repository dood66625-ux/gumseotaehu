2026-11-27 KST. 기존 저장 운명서를 22개 장면과 마지막 전체 보기로 구성한다. 대표 타입·아홉 장·직업/사람 TOP3·장단점·가까이/멀리할 것·국내 인물·올해의 당부·긴 편지를 그대로 재사용하며 추가 AI 생성을 하지 않는다.

초상과 글이 화면의 절반씩 보이고, 긴 글은 글상자 안에서 스크롤한다. 글상자를 위로 넓히거나 접을 수 있다. 장 이동 때 상자 상태를 초기화하고 세션 저장소에는 주문별 장 번호만 저장한다. 마지막 전체 보기에서는 상세 팝업 대신 본문을 모두 표시한다. 장별 보기 중 인쇄해도 전체 운명서가 출력된다. 전체 보기는 숨김 상태로 유지해 자문 입력 초안을 보존한다.

모바일 복구 링크를 숨기던 마지막 링크 CSS를 바로잡았다. 출생정보·무료 풀이·결제에도 복구 링크를 표시한다. 높이 740px 이상 입력 화면은 중앙에 배치하며 작은 화면의 입력칸 잘림 방지 규칙은 유지한다. 기존 비공개 리더의 긴 글도 팝업 대신 위로 펼쳐지는 내부 스크롤로 바꿨다.

상용 콘텐츠 안내·약관의 자문 제공 문구를 실제 기능에 맞추고, 공개 메인/정책만 검색 허용한다. 개인 운명서·관리자·입력·복구 등은 검색 대상에서 제외한다. 결제·AI·메일 활성화, 키, 예산과 서명 등록은 변경하지 않는다. 외부 심사/법무/운영 인수의 완료를 뜻하지 않는다.

## 모바일 입력 초상 잘림 수정

아이폰 Chrome 화면 제보로 입력 단계에서 짧은 초상 영역에 화면 너비 기준 정사각 사진을 중앙 정렬하던 문제를 수정했다. 사진을 영역 높이에 맞춰 축소하고 상단 정렬해 왕관과 얼굴이 영역 위로 잘리지 않게 했다. 좌우 가장자리를 페이드 처리하며 기존 입력칸·버튼 높이 규칙을 유지한다. Chromium/WebKit 390×664·375×667·320×568·1440×900의 5단계에서 사진 상단/크기와 버튼 화면 내 배치를 검사한다.

사용자 후속 수정: 초상을 축소하는 접근을 취소했다. 원래 `min(100vw,560px)` 크기를 유지하고, 사진 영역을 너비의82%(최대460px)로 확보해 입력칸을 아래로 이동한다. 높이가 짧으면 세로 스크롤로 모든 입력과 버튼에 접근한다. 앞선 영역 높이 기준 축소 설명은 이 수정으로 대체한다. Chromium/WebKit 회귀 검사는 원래 크기 보존·얼굴 상단 포함·입력 영역 비중첩·다음 버튼 접근을 확인한다.
