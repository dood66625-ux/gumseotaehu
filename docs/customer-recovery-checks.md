# 문의·결제 상태 장애 복구 보강 — 2026-11-18 KST

## 수정

- 문의/환불 화면은 목록 조회의 401만 재인증 대상으로 처리한다. 일시적인 조회 장애는 조회 오류와 재시도 버튼으로 보여주며, 구매/문의 내역이 없거나 로그아웃됐다고 표시하지 않는다.
- 문의 POST 성공 시 표시한 접수번호는 후속 목록 조회가 실패해도 유지한다. `주문·문의 내역 다시 확인`은 GET 조회만 수행하며 같은 문의를 다시 POST하지 않는다. 접수 실패 오류와 목록 조회 오류는 별도 상태다.
- 결제 상태 조회는 응답이 끝난 뒤 2초 후 다음 조회를 예약한다. 느린 응답 위에 새 요청이 쌓이거나 이전 응답이 최신 응답을 덮는 일을 막는다. 화면 이동 후 재예약하지 않는다.
- 고객 화면의 worker 실행 명령은 추가 결제 없이 주문번호로 복구·환불을 요청하는 안내로 바꿨다.

## 검증

모바일/PC Chromium에서 문의 일시 장애→재조회, 접수번호 보존→재조회 시 POST 1회 유지, 세션 만료 시 재인증, 결제 상태 응답을 10초 보류하는 동안 중복 GET 없음→정상 상태 회복을 검사했다(8개). Next.js 빌드·타입·비밀값 검사도 통과했다. 처음 테스트 실행의 실패 4개는 Next.js 경로 안내용 별도 alert까지 선택하는 테스트 locator 문제였으며, 앱 경고 문구로 대상을 좁힌 뒤 해당 4개 모두 통과했다.

실제 로컬 SQLite/모의 결제/worker/PDF/이메일 재인증/문의/관리자 전액 mock 환불 경로의 기존 모바일 통합 시나리오도 통과했다(1개, 합계 9개). 이전 관리자 UI 변경 이후 남아 있던 오래된 환불 버튼/상태 locator도 현재의 명시적 모의 전액 환불 버튼과 완료 메시지에 맞춰 수정한 뒤 재검증했다. 공급자 API 요청이나 실제 카드 승인/메일 발송은 하지 않는다.

## 범위와 한계

접수 POST의 응답 자체를 잃는 상황에 대한 서버 멱등 접수 기능을 추가한 것은 아니다. 이번 변경은 성공 응답을 받은 접수가 목록 조회 장애 때문에 사라져 재접수하게 되는 문제를 해결한다. 실제 수신함, 업체 반송/운영 연결, iOS/Android 실기기·결제 앱 복귀 검증은 남아 있다. 정확한 iwinv 배포 커밋은 별도 확인하며 GitHub 패키지 발행만으로 서버 적용을 완료 처리하지 않는다.

## 공통 브라우저 요청 제한 — 2026-11-18 KST

`lib/client-api.ts`로 전송 코드를 분리했다. 세션 준비부터 실제 요청·응답 JSON 읽기까지 합산 20초 제한을 적용한다. AbortSignal을 전달하고, 전송기가 취소를 무시하더라도 화면은 제한 시간에 대기에서 벗어난다. 늦게 도착한 세션 준비 응답이 제한 시간 이후 결제/문의 POST를 시작하지 못하도록 차단한다. 세션 준비가 HTTP 오류나 잘못된 응답으로 실패하면 실제 변경 요청도 실행하지 않는다.

시간 초과나 연결 유실을 서버 취소/접수 실패/결제 실패로 단정하지 않는다. 변경 요청은 결과 불명확과 내역 확인 안내를 표시하며 이 전송 계층에서 자동 재시도하지 않는다. 기존 결제 상태 화면의 읽기 전용 GET 폴링은 별도다. 오류 응답이 HTML 등 JSON이 아니어도 HTTP 401은 보존하고, 파싱 오류 원문이나 HTML 본문을 화면에 노출하지 않는다.

구매 화면의 인증 상태 조회 실패도 처리하며, 출생정보 조회 오류에는 GET 재조회 버튼을 제공한다. 이 버튼은 주문 생성이나 결제를 수행하지 않는다. 문의 POST의 결과를 잃었을 때 입력 내용은 유지한다. 사용자가 직접 재접수하기 전에 내역을 확인해야 하며 서버 접수 멱등 기능이나 공급자 대사를 추가한 것은 아니다.

검증: 전송 단위 7개(무응답/응답 본문 지연/세션 실패/늦은 세션 응답/POST 응답 유실/비JSON 401/정상 처리), 모바일·PC 네트워크 E2E 6개, 기존 이메일 E2E 4개, 로컬 구매/PDF/재인증/문의/mock 환불 E2E 1개 통과. 정적 합성 체험판 전체 흐름도 통과했으며 외부 API 요청은 0건이다. 빌드·타입·비밀값 검사 통과. 실제 결제·메일·유료 AI 호출 및 고객정보 외부 전송은 수행하지 않았다.
