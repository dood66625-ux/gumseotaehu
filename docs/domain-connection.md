# gumseo.kr 연결 계획

운영자가 2026-11-16 서비스 도메인을 `gumseo.kr`로 확정했다. 구매/소유권·DNS·HTTPS·서버 연결이 검증됐다는 의미는 아니다. 현재 공개 체험판 주소와 로컬 APP_ORIGIN은 그대로 유지하며 DNS 변경·운영 공개 배포는 하지 않았다.

| 용도 | 계획 | 상태 |
|---|---|---|
| 정식 사이트 | https://gumseo.kr | 호스팅·DNS·TLS 미연결 |
| 발신용 도메인 후보 | mail.gumseo.kr | 업체 소유권 검증 필요 |
| 거래 메일 발신 후보 | archive@mail.gumseo.kr | 발송 비활성, 업체 설정 전 |
| 답장/문의 | mjreview3@gmail.com | 기존 운영자 제공 주소 유지 |

다음 준비는 Resend 후보 계정의 Domains에서 `mail.gumseo.kr`을 등록하고, 업체가 발급한 실제 DNS 레코드를 확인하는 것이다. 해당 단계는 계정 및 발신 도메인 준비이며 고객 메일 발송 허가를 대체하지 않는다. 발신 주소 후보도 최종 업체 설정 전에 확정한다.

가비아 DNS에 넣을 SPF/DKIM/MX 값은 업체가 보여주는 값으로만 구성한다. 현재 저장소에는 발급값이 없으며 임의 값을 만들지 않는다. 기존 NS/MX를 다른 값으로 바꾸거나 사이트용 A/CNAME을 넣기 전에 호스팅·현재 메일 사용 여부를 확인한다. 웹 서버가 정해지기 전에는 접속 IP를 지어내지 않는다.

DNS 공개 정보만으로 운영자 소유권을 증명할 수 없다. 실제 확인 결과와 계정 확인을 구분한다. API 키/로그인 비밀번호는 대화·DNS·Git에 넣지 않는다. DNS 화면에는 공개 레코드 값만 공유하면 된다.
