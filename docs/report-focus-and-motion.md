# 고민에 맞춰 읽기·무료 풀이 전환

- 일·직업 → 직업과 성장(5장), 대운(7장); 돈·재물 → 재물과 선택(3장); 인연·관계 → 연애와 인연(4장), 관계와 균형(6장); 나 자신 → 구조(1장), 성향(2장), 조언(9장). 기존 장으로 이동하며 새 해석이나 추천 사실을 생성하지 않는다.
- 웹 보고서는 해당 장으로 키보드 초점과 화면을 이동하고 관련 장 링크를 제공한다. 비공개 reader는 같은 매핑으로 해당 책장을 연다. 원문·PDF의 본문이나 생성/메일/결제 한도는 변경하지 않는다.
- 무료 풀이에는 방향에 따른 420ms 미세 회전·이동·명암 전환을 적용한다. 모든 내용은 유지하며 prefers-reduced-motion에서는 효과를 끈다. 인쇄에서도 끈다.
- 표정 8종은 기존 창작 초상을 참고해 만든 2×2 이미지 두 장으로 제공한다. 각 무료 페이지에 다른 칸을 표시하고 재사용한다. 원본 생성 결과는 generated_images에 보존하고 공개 PNG 사본만 패키지에 포함한다. 열람마다 이미지/API를 생성하지 않는다. 이번 생성은 공통 자산 제작이며 고객 정보가 포함되지 않는다.

390×664·320×568·1440×900에서 각 무료 화면 초상 존재/표정 중복 없음/진행 버튼 위치·가로 넘침·모션 줄이기를 점검했다. 웹과 비공개 reader에서 네 주제의 실제 목적 장 이동 및 추가 모델 요청 없음, 정적 합성 구매·PDF·재열람·문의·이메일 변경 흐름도 확인했다. 타입/전체 빌드/비밀값 검사 통과. 실제 단말 인수·계산 전문가 검수·실판매 승인을 대신하지 않는다.
