# 그대의 오행 · 금빛 진법 그래프

무료 풀이의 막대 그래프를 오각형 레이더 문양으로 교체했다. 목·화·토·금·수 순서와 계산값은 그대로이며, 최댓값에 대한 상대 비율로 도형을 그린다. 0개는 중심에 놓인다. 퍼센트나 신강·신약 판정이 아니다.

금빛 궤도와 격자, 다섯 가지 직접 그린 SVG 상징(나뭇잎·불꽃·산·보석·물결), 오행별 색과 정확한 개수를 표시한다. 최다 항목(동률 포함)은 문양 테두리를 강조하고 짧은 수량 설명을 보여준다. 선이 그려지고 문양이 순차 등장하며 동작 줄이기 환경에서는 애니메이션을 끈다. 고정 ID나 외부 이미지 요청 없이 벡터로 표시한다.

검증: 상용 빌드·타입·비밀값 검사 통과. 합성 데이터로 아이폰 WebKit, 모바일/PC Chromium에서 정확한 개수와 0의 중심 좌표, 360×740 및 320×568 화면 배치를 확인했다(3건). 실제 고객 데이터 조회와 AI·메일·결제 호출은 없다.
