# 환불/정정 처리표 (초안)
| 사유 | 기본 처리 |
|---|---|
| 결제 전 취소 | 청구 없음 |
| 이중결제 | PG 원장 대조 후 중복 건 전액 취소 |
| 결제 후 지속 미제공/생성 오류 | 재처리/재제공 또는 적법한 환불 |
| 창닫기·메일 미수신·PDF 분실 | 1년 내 무료 재열람·재발송·PDF 재다운로드 |
| 고객 출생정보 오입력 | 7일 내1회 정정 혜택 초안; 본인확인/이력 필수 |
| 계산/시스템 오류·계약 불일치 | 시정·재발급·법정권리 환불 |
| 정상 제공 후 변심 | 철회 제한 법정 요건 개별 검토, 일률 거절 금지 |
| 법정대리인 계약 취소 | guardian 문의 분류·증빙·법률/PG 검토 |
| 이메일 변경 | 문의/수동 신원 검토; 새 이메일 소유 검증 자동 기능 미구현 |

환불 요청→검토/사유 기록→refund_pending→모의 PG 취소→결과 대조→refunded. 실패시 pending/error 유지. 같은 주문 취소를 반복해도 취소원장1건. 완료 후 웹 접근 종료, 거래원장은 보존. 부분 환불·차지백 미구현. 실제 PG/정책·법정 환급 기한 검토 후 운영.
