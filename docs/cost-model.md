# 운영비 계산 틀
실제 공급자 단가/계약이 없으므로 비용이나 마진을 확정하지 않는다. 현재 로컬 AI·PG·메일 외부 비용은0이며 이것을 운영 원가로 사용하면 안 된다.

- 고객 결제총액:33,000원. 공급가/부가세는 사업자 과세 분류 확인 후 계산.
- AI 원가 = 무료 입력·출력 tokens × 모델별 단가 + 유료 보고서 tokens × 단가 + 재시도 원가. 실제 모델/환율/단가/일별 한도를 확정해야 한다.
- 주문별 공헌이익 = 과세 검토 후 매출 − PG 실제 수수료 − AI − 메일/PDF/저장소 변동비 − 광고 CAC − 환불·분쟁비.
- 월간 고정비 = 앱/워커 + PostgreSQL + 백업·키관리 + 관측/오류알림 + CS·법무·세무.
- CAC = 승인 전환으로 귀속한 광고비 ÷ 승인 고객 수. 현재 광고비 연동/동의 추적이 없어 계산하지 않는다.

관리자 표시 금액은 실제 저장된 모의 승인/환불을 집계한다. 실 API 사용량·원가·광고비·PG 정산을 연결하기 전 실제 수익성 분석은 BLOCKED다.
