# 직업·사람 유형 TOP3와 쉬운 대운

2026-11-23. 기존 저장 원문·계산값·예산·결제/메일 설정은 바꾸지 않는 표시 계층 변경이다.

- 일간 오행별로 직업 3개와 사람 유형 3개를 고르고 각 추천의 탐색 이유를 태후 말투로 제공한다. 순서는 편집상 추천 순서이며 직무 적성 검사·실제 상대의 사주 궁합 순위로 주장하지 않는다. 관련 안내를 함께 표시한다. 새로운 유료 모델 호출 없이 웹·비공개 reader·새로 생성하는 PDF에 공통 적용한다.
- 대운은 약 10년 단위라는 설명, 표의 나이/연도가 사건 예정일이 아니라는 읽는 법을 먼저 제공한다. 보고서 기준 연도를 포함하는 계산 구간이 있으면 저장된 시작·끝 연도와 계산상 시작 나이를 표시한다. 계산 구간이 없으면 임의의 시기·나이를 만들지 않는다. 순행/역행/교운기 등의 용어를 쉬운 말로 치환하고 원문의 조건·부정 조언은 유지한다. 기존 원문은 덮어쓰지 않는다.
- 계산 근거를 별도 연속 페이지로 보여주지 않고 미리보기의 접힌 안내로 보존한다. 기본 화면 흐름의 마지막은 구매 안내다. 실제 결제 후 주문 상태·운명서 열람 경로는 유지한다.

관련 8개 테스트·타입·전체 빌드·비밀값 검사, 390/1440 비공개 저장본 TOP3 3개씩·장 넘김·인쇄·AI 요청 0회, 미리보기 마지막 구매 화면과 320/390/1440 화면 크기 검증을 수행했다. 합성 PDF 생성도 확인했다. 실제 고객 생성·메일·결제를 활성화하거나 전문가 품질 검수를 완료한 것은 아니다.
