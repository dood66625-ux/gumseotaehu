# 운명서 콘텐츠 검수 1차

2026-11-14. 가상 데이터만 사용. 실제 AI 호출/과금/개인정보 전송 없음.

## 발견 및 수정
- 일간 설명만 반복하던 구조: 천간 십성·지지 육합/충·대운·대표 월운의 계산 기록을 별도 근거로 추가하고 장별 연결.
- 모든 고객에게 같던 월별 문장: 월간 천간과 일간의 십성에 따른 실천 질문으로 변경. 운세 사건이나 길흉 확정이 아님.
- 오행 동률인데 하나만 강조하던 무료 풀이: 공동 최다 요소를 모두 표시.
- 과도한 '검증된 계산 근거' 표기: 읽을 수 있는 '계산 기록'으로 변경. 독립 만세력 검수 완료로 표시하지 않음.
- PDF 목차: 실제 장 시작 쪽수 추가. 근거 ID 대신 계산 문장 표시.
- 검증: 원본 차트 불변, 연도 일치, 불확실성 원문 보존, 완전 중복 장 거부, 명시적인 일간/오행 개수 모순 및 소개문 위험 표현 차단.
- 프롬프트/초안 버전 taehou-3. 기존 저장 보고서를 재작성하지 않음. 구버전 차트는 추가 근거 부재를 명시하며 원본은 변경하지 않음.

## 검수 범위
10개 일간을 포함한 12개 사례(시각 미상, 대운 구분 미선택 포함). 9개 장 전체 4,099~4,371자, 장당 277~928자. 문장 수나 페이지 수를 유료 가치 검증으로 해석하지 않는다. 사례 산출물은 Git 제외된 var/content-review에 JSON 12개, PDF 3개로 저장한다. 재생성: `npm run audit:content`.

PDF 3개의 한글 텍스트 추출 및 9개 목차 쪽수 일치를 확인했고 목차 이미지를 시각 점검했다. 시간 미상 사례에서 대운 수치를 만들지 않음을 확인했다.

## 남은 상용 품질 조건
- 규칙 기반 문장은 여전히 공통 표현 비중이 높고, 전체 명리학 해석/전문가 검수나 실제 AI 품질 검증을 대체하지 않는다.
- 십성은 천간 기준 관계 표이며 지장간 전체 가중 해석이 아니다. 합충은 지지 조합 기록이며 합화·길흉/사건 성립을 판단하지 않는다.
- 일간/숫자 검사와 완전 중복 검사는 제한적인 자동 검사다. 의미가 같은 반복, 잘못된 인과관계, 은근한 불안 유도까지 완전 검출하지 못한다.
- 실제 AI 공급자 확정 후 합성 데이터로 장별 구체성/반복률/정합성/문체/원가를 추가 검수해야 한다.
- 전문가의 독립 달력/절기/대운 대조 및 법률 검토 전 판매 차단 유지.

## 실행 결과
타입 검사, 전체 단위/통합 214개, 브라우저 E2E 21개(모바일 Chromium/WebKit·데스크톱 Chromium), Next.js 프로덕션 빌드, 합성 체험판 구매/PDF/재열람/문의 테스트 통과. 처음 발견한 클라이언트/서버 import 경계 오류는 목차 모듈 분리로 수정했다. 긴 페이지의 WebKit 스크린샷 제한은 CSS 배율 촬영으로 해결하고 전체 E2E를 재실행했다. 실제 iPhone/Android 기기 검증이나 상용 품질 승인으로 간주하지 않는다.
