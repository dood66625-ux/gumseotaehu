# 운영자가 다음에 할 일

화면 수정과 별개로 현재 공개 주소는 고정된 가상 정보 체험판이며 실판매 상태가 아니다. 아래 항목을 순서대로 준비한다. API 비밀키·카드번호·계정 비밀번호를 대화나 Git에 올리지 않는다.

## 지금 먼저 정할 것
1. 사업자등록 유무와 판매에 사용할 상호. 기존 사업자가 있다면 업종/판매 범위는 담당 전문가와 확인한다.
2. 고객문의용 이메일/연락처. 실제 사업자·대표자·등록/신고 해당 정보는 운영 고지 확정에 사용한다.
3. 사용할 도메인 이름과 월 운영 예산 범위.

## 다음 계정 준비
- 토스페이먼츠 가맹점 신청/심사,테스트 계정과 키. 먼저 테스트 승인·취소·복구를 실제 샌드박스로 검증한다.
- OpenAI API 또는 확정한 AI 공급자의 사용 계정·결제/예산 한도. 키는 보안 설정으로 연결하고 샘플 품질·원가·오류 복구를 검증한다.
- 운영 서버/DB·메일 발신 계정과 도메인 인증. 현재 SQLite 로컬 코드를 운영 환경에 맞게 보완하고,메일·재열람·백업·보안 검증을 수행해야 한다.

## 유료 오픈 전 필수
- 명리학 전문가의 만세력/해석 검수,한국 달력·절기 독립 대조.
- 실제 사업자에 맞는 개인정보·약관·청약철회·환불·AI 표시·연령 확인의 법률/세무 검토.
- 실기기·실 PG·AI·메일·운영 DB의 통합 검증 후,운영자가 실제 결제/메일/개인정보 외부 전송/공개 운영 배포를 각각 명시적으로 승인한다.
