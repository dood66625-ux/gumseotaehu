# 판매가 22,000원 변경

운영자 명시 지시로 신규 종합 운명서 판매가를 **22,000원 일회성**으로 변경했다. 실제 판매 활성화 또는 외부 전송 승인이 아니다.

- `lib/product.ts`에서 신규 판매가/표시 금액을 공유한다. 랜딩·무료풀이·주문 확인·약관·합성 체험판·새 주문·모의 승인·안내 메일을 맞췄다.
- 결제 승인/조회/전액 환불은 현재 상품가격 대신 **해당 주문에 저장된 금액**을 검증한다. 기존 33,000원 주문과 원장·동의·보고서·환불 이력을 재작성하지 않는다.
- SQLite migration 8은 기존 `CHECK(amount=33000)`을 두 가격 허용으로 확장하되 행·FK·인덱스를 보존한다. 트랜잭션 실패 시 되돌리고 FK 설정도 복구한다. 실제 운영 데이터에 적용할 때는 기존 백업·복구 절차를 먼저 따른다.
- 새 주문은 서버에서 22,000원으로만 만든다. 예전 금액을 보낸 신규 주문 승인 요청은 거부한다. 오래된 주문을 같은 풀이의 새 22,000원 주문처럼 재사용하려고 하면 새 무료풀이 또는 기존 구매본 재열람으로 안내한다.
- 기존 열람 권한과 기간 안에서 과거 주문의 제공/재열람은 동일 원문을 유지한다. 가격 변경으로 새 결제나 재생성을 요구하지 않는다.
- Toss 계약/코어는 주문별 금액을 승인·조회·취소 요청과 응답에 모두 적용하며 취소 멱등키를 바꾸지 않는다. 기존 33,000원 전액 취소도 33,000원으로 대사한다.
- 승인 안내 메일은 임의 payload 금액이나 현재가가 아닌 저장된 주문금액을 사용한다. 실제 메일은 발송하지 않는다.
- 공개 합성 체험판 캐시 버전을 `royal-10`으로 변경했다. 실제 고객 입력·PG·AI 호출·메일 발송·관리자 공개는 계속 차단한다.

검증: 타입 검사, 단위/통합 438개, 모바일 Chromium/WebKit·데스크톱 E2E 33개 통과. 신규 금액 승인·옛 금액 변조 차단, 과거 주문 원문/전액 환불, 기존 DB 이전/실패 롤백을 추가 검증했다. 프로덕션 빌드/비밀값 검사 및 합성 체험판 구매/PDF/재열람 검사도 수행한다. 실제 Toss 샌드박스/운영 결제나 실 AI 성공을 검증한 것은 아니다.
