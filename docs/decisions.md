# 결정 기록
- 2026-11-13: 사용자가 승인한 mock 우선 개발. API 키 생성·실 API 연결은 진행하지 않는다.
- SQLite는 로컬 통합 검증 전용. PostgreSQL/HA/백업 암호화 키 관리 검증 전 출시 차단.
- lunar-javascript MIT 1.7.8 사용. 1989~2030 한국 출생으로 로컬 검증 범위를 제한한다. 해외/역사 DST/한국 음력 독립 대조 미검증은 거부 또는 출시 차단한다.
- 자시 00:00 일주 경계(sect 2), 진태양시 미적용, 절기 중국 표준시 보정 +1h. 대운은 해당 라이브러리 sect 2이며 전문가 확정 필요.
- 미성년 구매자 유료 API 항상 거부. 대상자 14세 미만, 타인 정보 수집은 초기 구현에서 거부.
- 출생시간 미상은 시주/대운 시작시각 산출 제외. 일주도 시간 경계 불확실성을 고지한다.
- 영상/이미지 원본 미첨부: 자체 SVG 정적 캐릭터 + CSS 5초 스토리. 폰트는 로컬 시스템, PDF는 OFL 한글 폰트.

- 성능 개선: 기본 App Router 랜딩 hydration의 Lighthouse LCP2.57~2.66초를 확인하여 root를 빌드 시 static HTML route로 변경. 다른 기능은 기존 App Router 유지. 첫 화면에 inline SVG를 사용하고 WebP는 다른 페이지에 유지한다. 프레임워크 자체 실행을 줄이는 방식이며 측정 도구/사용자에 따른 분기 없음.
