## 발견·수정

양피지 위 ‘풀이 근거 살펴보기’가 일반 summary의 밝은 글자색을 상속해 최소 대비가 약1.08:1이고 모바일 근거 글씨는9px였다. 어두운 갈색으로 지정하고 접힌 표식에도 같은 색을 적용했다. 펼친 근거는12px로 키웠다. 수정 후 모든 양피지 그라데이션 정지점에 대한 최소 대비는6.13:1이다. 그라데이션 배경을 자동 접근성 도구가 완전히 판정하지 못해 실제 계산 스타일의 색을 별도로 측정했다. 전체 WCAG 인증을 의미하지 않는다.

메인 검사2개가 이미 제거한 ‘스토리 건너뛰기’를 찾으며 시간 초과됐다. 삭제 버튼이 없음을 확인하고 현재 ‘내 사주 펼쳐보기’를 사용하도록 기존 검사를 수정했다. 초기 통과6개는 그대로 두고 해당2개만 다시 실행해 통과했다. 별도 저장본 표시 검사와 앱/worker 빌드·타입·비밀값 검사도 통과했다. [최소 실행 근거](customer-reading-review.json).
