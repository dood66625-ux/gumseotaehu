# 토스 테스트 연동 준비

## 이번 구현
- 테스트 키만 허용하는 선택형 HTTP transport. 앱/워커에는 아직 연결하지 않음.
- 토스 고정 호스트만 허용, 승인/주문조회/취소 경로 제한, 리다이렉트 차단.
- 서버 가격 33,000원 및 주문/결제키/승인·취소 상태 검증 계약 유지.
- 시간초과/네트워크 오류는 승인 상태 재조회가 필요한 오류로 반환. 자동 결제 재시도 없음.
- 공급자 오류 본문/인증정보를 오류에 노출하지 않음.

외부 호출 없이 가짜 fetch로 승인, 금액 불일치, 조회, 전액 취소, 401/429/500, 잘못된 JSON, 네트워크 실패, 시간초과를 검증했다. 실제 PG 통합 완료를 의미하지 않는다.

## 운영자가 지금 할 일
토스페이먼츠 공식 사이트 https://www.tosspayments.com/ 에서 개발자센터/테스트 환경 이용 가능 여부를 확인한다. 이미 계정이 있으면 새 계정을 만들 필요 없다. 테스트 클라이언트 키·테스트 시크릿 키가 표시되는 단계까지 준비하되 **키를 대화·스크린샷·공개 저장소에 올리지 않는다**. 키 연결은 추후 보안 환경설정으로 진행한다. 실결제 계약·활성화 또는 유료 상품 가입은 이번 단계에서 진행하지 않는다.

## 다음 개발
브라우저 테스트 SDK, 서버 주문 상태와 승인/조회/취소의 연결, 웹훅 신뢰 검증 및 재조회, 중복/동시 승인·승인 후 장애 복구의 실제 샌드박스 검증. 현재 체험판은 계속 합성 결제이며, 키만 추가해도 실판매가 활성화되지 않는다.

## 비공개 키 연결 절차 (개발 담당자용)
현재 GitHub Pages는 정적 체험판으로 비밀키를 저장하거나 결제 승인 서버를 실행할 수 없다. HTML/JS, GitHub 파일 편집, 채팅으로 시크릿 키를 전달하지 않는다.

비공개 개발 서버/운영 서버를 정한 뒤 담당자가 보안 설정을 안내한다. 로컬 개발에서는 Git 제외된 .env.local에 TOSS_TEST_CLIENT_KEY와 TOSS_TEST_SECRET_KEY를 설정할 수 있다. 저장 파일 권한은 0600을 유지한다. 호스팅에서는 제공자의 비공개 환경변수 기능을 사용한다. NEXT_PUBLIC 접두사는 사용하지 않는다.

`npm run toss:check`는 값 출력이나 네트워크 요청 없이 테스트 키 형식만 검사한다. 실제 키 유효성/가맹점 인증 검증이 아니며 키를 넣어도 앱의 mock 차단은 해제되지 않는다. 저장소 비밀 검사에는 두 변수도 포함된다.

운영자 테스트 키 화면 확인 완료. 실제 키는 아직 요청·수신·저장하지 않았다. 다음 결정은 한국 접속 속도와 백업/DB를 고려한 개발 서버 및 월 예산이다. 서버 비용 승인이나 유료 가입은 별도로 진행한다.
