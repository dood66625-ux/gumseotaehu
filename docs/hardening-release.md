# 운영 보강 릴리스

2026-11-14. 계정 없는 로컬/합성 검증 범위의 구현이며 상용 출시 완료가 아니다.

## 관리자·요청 보안
- 고객 이메일 인증과 관리자 승격 시 세션 토큰을 교체하고 이전 토큰을 폐기. 읽기/인증 요청의 소유 관계는 새 세션으로 이동.
- TOTP 사용 시점을 DB에 기록하여 같은 코드의 전역 재사용 거부. 다음 30초 코드를 사용해야 할 수 있음.
- 환불/정정/삭제/재시도/CSV는 최근 10분 내 관리자 인증 요구. 역할·만료를 DB에서 다시 확인. 전체 관리자 세션 종료 지원.
- 이메일 인증은 고객 인증 시각을 별도 기록. '취소된 인증번호'를 최근 본인인증으로 오인하지 않음. 고객 인증 시 관리자 권한은 해제.
- JSON 스트림을 읽는 중 16KiB 제한. Content-Length 누락/축소에도 적용. 배열/null/잘못된 JSON 거부.
- 설정의 MFA 시드 형식·정확한 origin·2027 상품 연도·SQLite 경로 검증.

## 결제·장애 복구
- 결제됐지만 생성 작업이 없으면 중복 없이 복구. 이미 제공한 원문이 없을 때는 재생성하지 않고 백업 복구 필요 상태로 집계.
- 만료된 주문의 생성/수동 재처리 거부. 잘못된 연령 정정으로 미성년 제한을 우회할 수 없음.
- 전액 모의 환불은 주문금액/결제키/취소ID/환불기록까지 대조해야 완료됨. 대조 실패 시 대기/오류를 유지.
- 작업자 heartbeat, 생성 실패/환불 오류/기한 경과 문의/원문 누락/승인 대사를 관리자 화면에 표시.
- 관리자 주문은 최근 200건과 서버 검색. 집계는 전체 주문 기준. CSV는 최근 5,000건의 가림 처리 주문 필드만 제공.
- 출생정보 정정은 JSON 편집 대신 일반 필드로 입력.

## 이메일 변경
기존 구매 이메일을 최근 10분 내 인증하고 새 주소의 15분 OTP를 확인한 경우만 해당 유료 주문과 연결 문의의 주소를 변경. 5회 오류/만료/대체 요청/타 세션 거부. 이전·새 주소의 세션을 폐기하고 새 주소 재로그인 후 동일 원문을 제공. 기존 주소를 사용할 수 없는 경우 자동 변경하지 않고 구매 증빙 문의 절차로 남김. 현재 이메일은 전부 로컬 outbox이며 실제 소유 인증을 검증한 것은 아님.

공개 체험판에는 고정 가상 주소 두 개만 허용한 별도 시뮬레이션을 제공. 실제 이름/출생/이메일/문의 입력·실 API 호출·관리자 접근은 계속 차단.

## 개인정보·키 교체
삭제 tombstone을 저장하고 서명된 목록을 내보낼 수 있음. 복구 CLI는 최신 목록을 필수로 받아 복구 DB의 출생정보/보고서를 다시 삭제한 뒤 새 파일을 제공. 잘못된 서명/키를 거부. 최신성 및 외부 동기화는 담당자 확인 항목.

오프라인 DATA_KEY 회전은 원본을 유지한 새 사본에서 모든 암호화 필드를 바꾸고 복사된 세션을 폐기. 새 키의 원문/결제 상태와 원본 보존을 테스트. AUTH_SECRET/관리자 자격증명/운영 KMS 회전은 미완료. 이전 키의 백업도 현재 키로 서명한 삭제 목록을 적용하고 현재 키로 재암호화해 복구할 수 있음. 자세한 명령: runbook.md.

## 출시 점검
`npm run readiness`: 비밀값/외부 요청 없이 구현·계정·전문가 검수·승인 차단 항목을 출력하며 현재 종료코드는 1. `--expect-blocked`는 CI에서 차단 유지 여부를 검사. 계정만 넣으면 출시 준비가 끝났다고 표시하지 않음.

## 남은 범위
실제 Toss SDK/서버/웹훅 및 샌드박스 통합, 실제 AI·메일 어댑터와 비용/실패 처리, 운영 인프라·분산 보호, 운영자별 MFA/권한 수명주기, 승인된 거래 보존/법적 보류/오프사이트 삭제 전파, 광고 동의/실측, 전체 명리/법무/실기기 검수는 여전히 필요하다. 모든 외부 효과는 비활성화 상태다.
