# iwinv 초기 서버 선택

2026-11-16 운영자가 iwinv를 선택했다. 서버 구매·접속·배포는 아직 수행하지 않았다.

## 신청할 사양

- 가상서버 → General Purpose → 공유형 `vgna_2_n`
- 공유 2 vCPU / RAM 2GB / NVMe 50GB
- 월 13,100원, 부가세 포함 14,410원(신청 화면 최종 금액 확인)
- 국내 리전, Ubuntu 24.04 LTS x86_64 기본 OS 이미지
- 유료 부가 옵션은 자동 선택하지 않는다. 외부 백업은 별도 구성·복구 검증이 필요하다.

공식 상품: https://www.iwinv.kr/server/server

## 구매 후 확인할 정보

서버 생성 완료 여부, 공인 IPv4, OS 이름만 먼저 확인한다. 비밀번호·개인키·API 키를 대화나 GitHub에 게시하지 않는다. 접속은 후속 단계에서 전용 SSH 키와 제한된 계정으로 구성한다. 공인 IP만으로 개발 환경에서 서버에 접속할 수 있는 것은 아니다.

## 개발자가 이어서 구성할 작업

1. SSH 키 인증, 제한된 관리자 계정, 방화벽, 보안 업데이트를 구성하고 재접속을 검증한다. 검증 전에 기존 접속을 끊거나 차단하지 않는다.
2. Docker와 재시작 정책을 구성한다. 이미지 빌드는 GitHub에서 실행해 2GB 서버의 빌드 메모리 부담을 줄인다.
3. 최초에는 합성 데이터 전용 비공개 검증 환경만 준비한다. 현재 mock 인증 경로와 SQLite를 운영용으로 공개하지 않는다.
4. 영구 데이터와 암호화 키의 보관, 서버 외부 백업, 복구 시험, 디스크·서비스 장애 알림을 구성한다.
5. 테스트 통과 후 배포하는 절차를 만들고 운영 반영은 명시적 승인을 받는다. 코드 롤백이 DB 롤백까지 보장하지 않음을 구분한다.

루트 도메인 웹 DNS는 아직 변경하지 않는다. 기존 Resend 메일 DNS 레코드는 보존한다. 실제 고객 데이터·결제·이메일 및 운영 공개는 별도 명시적 승인 전 비활성 상태를 유지한다.
