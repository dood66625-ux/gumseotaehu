## 자문 화면과 기록 팝업 정리

사용자 후속 요청에 따라 본문은 `태후에게 세번의 자문을 구하거라 (남은 횟수/3)`·입력칸·입력칸과 같은 너비의 자문 구하기 버튼으로 줄였다. 중복 장 제목·펼침 도구·안내/글자수 문구를 자문 장에서 숨기고, 모든 장의 오른쪽 PDF 안내 문구도 제거했다. 50자 제한은 그대로다.

답문은 금빛 테두리의 모달에 표시한다. 첫번째/두번째/세번째 탭으로 기록을 선택하고, 아직 요청하지 않은 탭은 비활성화한다. `감사합니다.`로 닫은 후 제목 옆 기록 아이콘으로 다시 열 수 있다. 대기 중에도 이전 탭을 볼 수 있고, 답변 도착이 읽고 있던 과거 탭을 강제로 바꾸지 않는다. 다른 장으로 이동하면 모달을 닫으며 대기 요청/초안/기록을 잃지 않는다. 재열람은 GET/로컬 탭 이동만 수행하며 자문 차감이나 추가 생성 요청을 하지 않는다. 기존 PDF 기록과 서버 권한·예산·요청 중복 방지는 변경하지 않는다.
