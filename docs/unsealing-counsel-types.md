## 변경

- 정상 작성 중: 검은 화면에서 적청 태극이 3초 주기로 작게 호흡한다. `운명서 펼치는 중…` 문구와 재열람 경로를 제공한다. 동작 줄이기 설정에서는 정지한다.
- 완료: 완료된 서버 상태를 받은 즉시 `운명서가 펼쳐졌느니라. 그대의 이야기를 확인해 보겠느냐?` 모달을 연다. 임의 대기 시간이나 가짜 진행률을 추가하지 않는다. 닫았다 다시 열 수 있다. 보류/실패/취소/기한 만료는 기존 정확한 상태 안내를 유지한다. 구매 증빙은 완료 화면에서 계속 이용할 수 있다.
- 주문 조회는 앞 응답 완료 뒤 1초 간격(기존2초)으로 수행하고 완료/종료 시 멈춘다. 진행 중 요청을 겹쳐 보내지 않는다.
- 장 이동 때 위로 펼침 상태를 유지한다. 마지막 편지 뒤에 독립 자문 페이지를 넣고 전체 보기에도 자문 바로가기를 둔다. 동일 자문 컴포넌트를 계속 유지해 입력 초안/요청 상태를 보존한다. 기존 주문별3회·50자·PDF 기록/비용 통제는 변경하지 않는다.
- 10종 대표 타입 이미지를 새로 제작해 5×2 단일 시트로 묶었다. 웹 WebP319390바이트, PDF JPEG435637바이트. 무료 타입 카드·운명서 타입 장면·전체 카드·PDF 전용 타입 페이지에서 같은 순번으로 선택한다. 원본 생성 그림은 generated_images에 보존하고 형식 변환만 수행했다.
