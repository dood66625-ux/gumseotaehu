# 방문 기록 관리자

`/admin/visitors`는 기존 운영자(operations) 인증 및 최근 추가 인증으로 보호한다. 방문 세션별 최초/최근 접속 시각(KST), 유입 사이트 호스트, 진행 이력, 연결된 주문의 서버 결제 상태를 표시한다. 구매 운명서 팝업은 저장된 최신 주문 버전을 읽고 조회 사실을 감사 기록에 남긴다. 삭제·보관 만료 자료는 열람할 수 없다.

방문 기록은 최초 접속부터 30일 보관한다. 쿠키는 임의 세션 식별자이며 HTTPOnly·SameSite=Lax이고 HTTPS에서 Secure다. 데이터베이스에는 해시만 보관한다. 방문 로그에 이름·생년월일·전체 IP·정확한 위치·유입 URL의 경로/쿼리를 복제하지 않는다. 유입 사이트는 지리적 위치가 아니다. 수집 이전 방문은 복원하지 않는다.

공개 개인정보 고지의 수집 항목에만 서비스 이용기록과 목적·보관 기간을 추가했다. 별도 배너는 추가하지 않았다. 로그 수집 실패는 고객 흐름을 중단하지 않는다. 클라이언트 이벤트만으로 구매 승인을 인정하지 않는다. 공개 체험 화면의 가상 주문은 실제 구매 전환으로 기록하지 않는다. 별도 비공개 reader 서버는 이 수집 대상에 포함되지 않는다.

## 기존 서버 최초 적용

자동 런타임 배포가 완료된 뒤 서버에서 한 번 실행한다. 새 API가 배포되지 않았으면 설치 스크립트가 중단한다. 공개 프록시에 수집 API와 관리자 화면·인증 API·Next 정적 리소스를 허용한다. 그 밖의 고객 API는 계속 차단한다. 관리자 데이터는 기존 비밀번호·MFA·역할 검사로 보호한다. 이번 최초 경로 설치는 프록시만 재생성한다. 이후 일반 배포 동작은 변경하지 않는다.

```sh
cd /opt/gumseo/source && git pull --ff-only && sudo bash deploy/iwinv/enable-visitor-log.sh
```

도메인에서 `https://gumseo.kr/admin`으로 접속해 기존 비밀번호와 일회용 인증코드로 로그인한 뒤 `https://gumseo.kr/admin/visitors`를 연다. 관리자 비밀번호/키나 결제·메일·AI 활성화 설정을 바꾸지 않는다. 로컬 SSH 터널도 기존처럼 사용할 수 있다.

검증: 방문 보관·유입 정보 최소화·서버 결제 연결·권한/추가 인증·삭제/만료 차단·허위 구매 이벤트 거절 단위 테스트, 브라우저 팝업/닫기/인증 만료 시 데이터 제거 확인. 실제 고객 정보나 외부 결제·AI·메일을 사용하지 않는다.

## 소유자 로그인 정보 확인

기존 관리자 비밀번호를 모를 때 서버 소유자의 대화형 SSH 터미널에서 `sudo bash deploy/iwinv/show-admin-login.sh`를 실행한다. 현재 실행 중인 일반 앱의 비밀번호와 현재 30초 TOTP만 해당 터미널로 표시하며 키나 설정을 변경하지 않는다. 등록용 MFA seed는 표시하지 않는다. 파이프/로그 수집 환경에서는 실행하지 않으며 출력 화면을 채팅이나 스크린샷으로 공유하지 않는다. 이 명령은 웹 MFA 검사를 우회하지 않는다.

## 2026-11-25 변경: 비밀번호 로그인·중복 접속

앞의 일회용 인증코드 안내를 대체한다. 관리자 로그인은 비밀번호만 확인하며, 로그인 시 기존 고객 세션을 회전하고 30분 관리자 세션을 발급한다. 중요한 조회/작업은 최근 10분 로그인을 요구한다. 비밀번호 오답 시 기존 횟수 제한을 유지한다.

서버 소유자는 `sudo bash deploy/iwinv/set-admin-password.sh`에서 12~200자 비밀번호를 두 번 비공개 입력한다. Scrypt 해시만 기존 DB에 저장하며 고객 세션, 기존 암호화/서명 키, 결제·AI·메일 설정은 유지한다. 기존 관리자 세션은 종료한다. 로그인 후 관리자 페이지의 비밀번호 변경에서도 현재 비밀번호 확인 후 변경할 수 있다. 기존 show-admin-login.sh는 더 이상 비밀번호나 OTP를 출력하지 않는다.

현재 Caddy 설정을 enable-visitor-log.sh로 다시 설치해야 신뢰 가능한 X-Gumseo-Client-IP 헤더가 전달된다. 프록시는 외부에서 보낸 같은 헤더를 덮어쓴다. 수집 서버는 이 헤더가 없는 로컬 모의 요청과 알려진 bot/headless 자동화 UA를 제외한다. 브라우저에서 만들어낸 승인 상태는 구매로 인정하지 않고, 관리자 구매 목록에는 실제 PG 주문으로 확인된 항목만 표시한다. 공개 체험 화면에 방문한 실제 사람의 방문은 집계하되 체험 결제는 집계하지 않는다.

IP 원문은 저장하지 않는다. 30일 구간별 HMAC 식별값으로 같은 접속망의 방문을 묶고 30분 이상 비활동 후에는 새 방문으로 기록한다. 페이지당 15개 묶음, 중복 접속은 기본 접힘으로 최근 100개 세션까지 펼칠 수 있다. 같은 IP는 같은 사람을 보장하지 않는다. 관리자 로그인에 사용한 접속망을 30일 제외 대상으로 등록하며 해당 구간 기존 기록도 지운다. 관리자 세션 자체도 집계하지 않는다. IP가 바뀌면 다시 로그인해야 그 접속망이 관리자 것으로 등록된다. 같은 공유기/회사망의 다른 사람도 함께 제외될 수 있다.
