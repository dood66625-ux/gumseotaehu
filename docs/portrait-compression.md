# 초상 용량·태후 말투 보정

첫 장을 높은 우선순위로 preload하고 다음 시트를 낮은 우선순위로 준비한다. PNG는 기존 주소 호환을 위해 보존한다. WebP는 손실 압축이며 픽셀 동일성을 주장하지 않는다. FFmpeg SSIM 비교는 각각 약 0.9881이며 전체 화면을 시각적으로 확인했다. 실제 통신 속도나 모든 단말에서의 로딩 시간을 보장하는 수치는 아니다.

화살표의 배경·테두리·box shadow를 없애고 화면 높이 50%에 중앙 정렬한다. 키보드 포커스 링은 유지한다. 마지막 장에는 태후의 준비 질문을 먼저 배치하고 아래에 기존 가격·checkout 링크를 둔다. 풀이 본문·인사말의 ‘입니다/합니다’ 등만 표시 계층에서 바꾸며 원문/계산/조건/부정 표현과 법률 문서는 유지한다.
