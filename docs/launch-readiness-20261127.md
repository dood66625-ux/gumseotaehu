# 출시 준비 현황 재점검 · 2026-11-27 KST

기능·공급자 연동 구현과 실운영/전문 검증을 같은56개 완료 조건으로 관리한다. 2026-11-26의41/56(73.2%)는 실제 판매 전환 후 확인된 내용을 반영하지 않은 상태였다. 현재 대화의 사용자 실행 결과와 이용 확인을 반영하면 **43/56(76.8%)·13개 남음**이다. 이는 작업 시간이나 매출 운영 안정성의 비율이 아니다. 실제 판매 경로는 이미 가동 중이고, 최종 검증은 별도로 남아 있다.

## 이번에 완료로 갱신한 두 항목

- **3.1.4 현 도메인 카드 승인→운명서 열람 확인**: 이전 이름은 새 도메인 TEST 승인 전체 흐름 확인이었다. 사용자는 운영 결제창을 이용한 후 실제 주문의 생성 보류 화면을 제시했고, 복구 뒤 `응 이제 잘 보이고`라고 운명서 열람을 확인했다. 신규 도메인의 승인·열람 검증은 이 승인된 실거래 확인으로 대체한다. TEST를 새로 실행했거나 처음부터 무오류였다고 주장하지 않는다. 환불/접근 종료 통합 검증과 최신 버전의 성능/전체 인수는 별도 미완료다.
- **6.2.2 판매 범위·모델/예산·실결제/실메일 활성화 승인**: 사용자는 한국어22,000원 상품, 기존 AI 키 재사용과 지정 경로 저장, 풍성한 답변, 일괄 판매 전환을 지시하고 서버에서 --activate를 실행해 SALES_ACTIVATED 결과를 제시했다. 기존 고정 모델/서명 설정과 예산 안에서 실제 결제·메일·AI를 사용하는 서비스 활성화 결정이 이미 제공됐으므로 반복 승인 대기로 두지 않는다. 실제 메일 수신/반송·정산조건 확인은 별도 항목에 남긴다.

위 두 항목은 대화의 사용자 확인을 근거로 한다. 이번 점검에서 운영 DB/PG 원장을 직접 조회하거나 새 결제·환불·AI·메일 호출을 실행한 것은 아니다. 공개 도메인/배포 반영과 모의 브라우저 검사를 실거래 증거로 대체하지 않는다.

## 공개 메뉴 정리

환불 정책의 이메일 앱 실행 버튼을 제거하고, 복사할 수 있는 접수 이메일과 신청 정보/처리 기한을 남긴다. 공개 공통 메뉴의 관리자 링크는 제거하며 /admin 직접 접근의 기존 로그인/권한 검사는 유지한다. 관리자 화면 내부 운영 링크와 robots의 개인 경로 제외 설정은 그대로다.

사용자 요청에 따라 이 프로젝트 답변 마지막에 https://gumseo.kr/admin 링크를 계속 제공한다.

## 사용자 실사용 확인 추가 · 2026-11-28 KST

사용자가 다음을 확인했다.

- 아이폰은 잘 작동한다. 안드로이드는 잘 되는 것으로 보인다고 했다. 최신 카카오톡 파일 공유/결제 앱 복귀까지 모두 확인한 것으로 확대하지 않는다(1.2.4는 진행 중).
- 인증번호·운명서 준비 안내와 다른 메일도 실제로 잘 도착한다. 4.2.3의 정상 수신은 사용자 확인으로 기록하고, 반송/웹훅 처리는 아직 진행 중으로 둔다.
- 자신의 거래로 토스페이먼츠에서 직접 환불을 해 봤다고 했고, 이어 관리자에서 환불 처리한 운명서는 더 이상 볼 수 없다고 확인했다. 기존 실승인/열람 확인에 이 실제 환불·웹 접근 종료 확인을 더해 3.2.4를 완료로 반영한다. PDF API는 동일한 getReport 권한 검사와 기존 차단 검증을 유지한다. 이번 대화에서 새 PDF 접근 시험을 한 것은 아니다. 토스 대시보드 단독 취소 이벤트의 자동 동기화까지 확인했다고 확대하지 않는다.

이번 반영은 사용자 확인을 근거로 한 기록 갱신이다. 새 결제/취소/메일/AI 요청이나 운영 원장 조회는 실행하지 않았다. **44/56(78.6%)·12개 남음**으로 갱신한다. 운영 보안 연결1개와 현장/전문 검증11개가 남으며, 정상 메일 수신과 반송 처리를 구분한다.
