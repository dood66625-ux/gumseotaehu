# 비공개 실제 AI 운명서 · 한국어/臺灣繁體中文

사용자가 실제 AI 해석을 선택한 범위에 따라 별도 초대 페이지를 만들었습니다. 기존 공개 합성 체험판·모의 결제·일반 worker를 운영 서비스로 전환하지 않습니다. 유료 결제와 이메일 발송은 없습니다.

## 기능과 계산 범위

- 한국어와 대만 번체중문 UI/실제 OpenAI 해석, 9개 장·공통 그림·쉬운 마무리·브라우저 인쇄/PDF.
- 양력, 만19세 이상 본인. 한국 출생은 1989년 이후 UTC+9, 대만 출생은 1980년 이후 UTC+8만 지원합니다. 역사적 서머타임·다른 출생국가·진태양시·민국 연도 입력은 지원하지 않습니다.
- 대만 절기 시각은 라이브러리의 UTC+8 기준으로 처리하며 한국처럼 1시간 보정하지 않습니다. 경계 시각은 확정하지 않고, 시간 미상은 시주/대운을 제외합니다. 사주 전문가의 독립 정확성 검수 완료를 의미하지 않습니다.
- 정상 서비스의 기존 한국 출생 스키마·지원 연도는 유지합니다. 계산 코어를 분리하고 별도 페이지에만 TW를 허용했습니다.

## 접근과 개인정보

초대 토큰은 256비트 난수이며 서버가 검증합니다. 로그인 후 토큰 없는 주소로 이동하고 HttpOnly·SameSite=Lax·HTTPS Secure 쿠키를 사용합니다. 검색/캐시/리퍼러/프레임 노출을 제한합니다. 링크 공유는 접속 권한 공유이며, 서로 다른 접속자는 다른 사람의 결과를 열 수 없습니다.

브라우저에서 명시적 동의를 받아 서버 계산 후 사주 정보만 OpenAI에 전송합니다. 이름·이메일·원본 출생일은 모델 요청에서 제외합니다. 입력 원본은 별도 DB 기록에 남기지 않고 저장 결과에서도 `solarDate`를 제거합니다. 계산된 기둥·대운 등의 개인 사주 정보는 결과에 포함됩니다. 결과는 AES-GCM으로 암호화하고 생성 24시간 이후 열람을 종료하며, 실행 중 정기/요청 정리 대상으로 삭제합니다. 서버가 정지한 동안 물리 삭제 시점은 보장되지 않습니다. API의 `store:false`가 제공자의 모든 법정/보안 로그 삭제를 의미하지 않습니다.

같은 세션의 같은 사주·언어는 저장본을 재사용합니다. 입력·결과를 브라우저 localStorage에 저장하지 않습니다. 원장은 삭제하지 않습니다. 재시작 당시 진행 중인 요청은 보류로 표시하여 자동 재생성하지 않습니다.

## 비용과 검증

기존 키 재사용 승인에 따라 별도 DB에서 가상 생년월일 2건을 실제 생성했습니다. 한국어 9장 377~709자, 번체중문 9장 352~778자. 지시의 목표 350~650자보다 긴 월별 장은 있으나 최소 길이/12개월/시각 미상/주의문 검사는 통과했습니다. 번체 본문에 한글이 섞이지 않는 검사도 추가했습니다. 본문의 전체 전문 품질/사실성 보증은 아닙니다.

확인된 사용량 추정 비용은 한국어 USD 0.015102 + 번체 USD 0.021023 = USD 0.036125(목록 가격 추정, 실제 청구서 아님). 모바일 양 언어·9장 그림·인쇄/PDF·가로 넘침 없음·재열람 추가 API 0회를 확인했습니다. 민감한 접근 파일·원장·실제 출력은 `var/private-reader`에만 있고 Git/패키지에 넣지 않습니다.

검증용 서버는 총10회 예약 중2회를 사용했습니다. iwinv 설치 기본값은 남은 범위인8회, 1회 USD 0.06 예약·합계 USD 0.48입니다. 실제 사용량이 더 적어도 예약 여력을 자동 환급하지 않습니다. 재시작/재설치 때 보관 디렉터리를 지워 한도를 초기화하면 안 됩니다. 추가 예산/횟수 변경은 별도 결정 사항입니다.

## iwinv 최초 설치

Cloud 작업환경에는 서버 SSH 키가 없고 임시 외부 주소 발급 요청이 차단되어 상시 접속 주소를 직접 열지 못했습니다. 아래는 코드/런타임 준비를 마친 뒤 운영자가 한 번 실행하는 설치입니다. root 소유 프록시 경로와 별도 환경 파일을 갱신하므로 최초 실행이 필요합니다.

```bash
cd /opt/gumseo/source && git pull --ff-only && sudo python3 deploy/iwinv/setup-private-reader.py
```

최신 런타임이 발행되어 있어야 합니다. 설치기는 기존 업데이트 helper로 런타임을 가져와 검사합니다. `/etc/gumseo/private-reader.env`에 키가 있으면 재사용하고, 다른 경로에서 찾은 키를 새 파일에 쓸 때는 yes 확인을 받습니다. 없으면 해당 서버의 숨김 입력창으로 입력하며 키를 출력하지 않습니다. 키를 채팅에 보내지 않습니다.

별도 loopback3450 서비스와 `/var/lib/gumseo-private-reader` 영속 저장소를 만들고, 기존 `pay.gumseo.kr` 프록시에 `/private-reading`만 연결합니다. 프록시 설정 검증에 실패하면 기존 파일을 복원합니다. 성공하면 아래 형식의 실제 초대 주소가 서버 터미널에 출력됩니다. 예시 토큰을 사용해 접속하면 안 됩니다.

`https://pay.gumseo.kr/private-reading/invite/<서버에서 만든 비공개 토큰>`

페이지용 URL·키·DB는 공개 패키지에 포함하지 않습니다. 기본 체험 사이트·토스 심사 경로는 유지합니다. 운영 서비스 설치/실제 URL 접속은 이 작업환경에서 아직 확인하지 못했습니다.
