# 암호화 백업/복구 검증

2026-11-14 로컬 가상 데이터 검증 결과.

- 타입 검사, 전체 208개 단위/통합 테스트, Next.js 프로덕션 빌드 통과.
- WAL 포함 일관 스냅샷을 AES-256-GCM 파일로 저장. archive 0600, 임시 폴더 0700.
- 새 파일로만 복구하며 기존 목적지/SQLite sidecar와 충돌하면 거부.
- 잘못된 키와 암호문 변조를 검출하고 복구 파일을 제공하지 않음.
- SQLite 무결성/외래키 오류 검출, 임시 파일 정리 확인.
- 앱 서비스의 가상 결제 주문과 저장 보고서를 복구한 뒤 paid 상태와 복호화된 원문 동일성 확인.
- 외부 호출, 실 결제, 실 이메일, 고객정보 외부 전송, 운영 배포 없음.

한계: 64MiB 파일 상한, 메모리 기반 암복호화, 로컬 디스크만 사용. 키 분리보관/운영 디스크 암호화/오프사이트 백업/보존기한·법적 보류·삭제 전파/운영 재해복구 훈련은 미완료. 임시 평문 파일 삭제는 저장매체 보안 소거를 보장하지 않음. 기존 평문 백업을 자동 삭제하지 않음. UI 흐름 변경이 없어 이번 단계에서 브라우저 E2E는 재실행하지 않았음.

후속 보강: 복구 사본에서 인증 세션/챌린지를 폐기하고 메일을 공급자 대사 전 보류하도록 추가했다. 주문과 보고서는 유지하고 원본 DB는 변경하지 않는다. 이는 기존 파일 복구 시험에 추가된 기본값이다. 현재 검증과 한계는 mail-delivery-integration.md를 따른다.
