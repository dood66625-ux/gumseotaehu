# 그림으로 읽는 금서태후

웹 보고서와 PDF의 본문 뒤에 쉬운 풀이, 돈·관계·일·시간 흐름의 공통 실천 안내, 용어 풀이를 제공합니다. 기존 저장 보고서의 본문·버전·다이제스트를 수정하거나 모델을 다시 호출하지 않습니다. 일간 오행에 따른 상징 설명이며 개인별 AI 본문 전체를 요약한 것으로 표시하지 않습니다. 대운 미산출은 그대로 명시합니다.

## 재사용 이미지

2026-11-18에 이미지 생성 도구로 공통 원화 두 세트를 제작했습니다. 중국 궁정 공필화와 청록산수에서 영감을 받은 옥색·주홍색·금빛의 동일한 화풍을 사용합니다. 챕터 9종, 오행 5종, 표지용 정원 1종을 개별 정적 자산으로 최적화했습니다. 한국 궁중풍 초안은 사용하지 않고 중국식 월문·태호석·회와 지붕·격자 정자를 포함한 새 원화로 교체했습니다. 그림은 정원·목련·들판·학·정자·강·계절·책을 통해 각 장의 주제를 표현합니다. 불은 파괴적 불길 대신 따뜻한 해와 모란으로, 금은 무기 대신 밝은 수정과 목련으로 표현합니다. 모든 사람에게 같은 감상을 보장하거나 재물·관계의 결과를 약속하지 않습니다.

`public/report-art/`의 이미지는 웹·PDF·정적 심사 사이트가 공유합니다. `lib/report-art.ts`에서 챕터별 이미지와 설명을 관리합니다. 기존 5종 기하 도해는 새 오행 그림으로 교체했습니다. 홈페이지에는 3종 미리보기 갤러리를 추가하고 보고서에는 장별 그림·캡션, 정원 표지, 쉬운 풀이 영역을 적용했습니다. 정적 미리보기의 서브경로도 지원하며 빌드 시 이미지 폴더를 함께 복사합니다.

생성 도구 사용은 이번 제작 시에만 이루어집니다. 고객별 그림 생성·외부 이미지 요청·추가 모델 호출은 없으며 사용자 입력을 그림 생성에 사용하지 않습니다. 초상과 본 그림은 AI로 제작한 창작 이미지입니다.

## 검증

저장된 가상 AI 보고서로 추가 API 호출 없이 브라우저에서 PDF를 다운로드했습니다. 15쪽, 약 1.06MB이며 첫 챕터의 그림·한글 배치를 렌더링으로 확인했습니다. 모바일 390px과 데스크톱 1440px에서 챕터 그림 9종 디코딩, 홈페이지 갤러리, 가로 넘침 없음, 저장 보고서 다이제스트 유지, PDF 다운로드를 확인했습니다. 원본 DB와 예산은 보존하며 브라우저 검증은 임시 복사본을 사용합니다.

출생시각 미상 처리·저장 본문 불변·5종 로컬 자산 선택 검증 2개, 타입 검사, 빌드·비밀값 검사를 통과했습니다. 디자인 완성도 보강은 고객용 AI·실결제·메일 활성화나 카드사 심사·전문가 감수 완료를 의미하지 않습니다.
