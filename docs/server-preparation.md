# 서버 가입 전 준비

현재 호스팅 계정은 없다. 서버 가입, 유료 요금제, 카드 등록, 공개 운영 배포를 수행하지 않았다. GitHub Pages는 합성 데이터 체험판으로 유지한다.

## 로컬 컨테이너
Docker/Compose가 설치된 개발 머신에서:

```sh
npm ci
npm run setup
docker compose build
docker compose up -d
# http://localhost:3000
docker compose ps
docker compose down
```

이 구성은 외부 연결을 끈 mock 검증 전용이다. 웹 포트는 127.0.0.1에만 바인딩한다. 비밀값은 이미지에 복사하지 않고 Git 제외된 .env.local에서 런타임에 읽는다. 앱과 작업자는 동일한 var 디렉터리를 공유한다. 호스트 var 디렉터리는 UID 1000이 쓸 수 있어야 하며 타 사용자 공개 권한은 주지 않는다. 실 고객 정보를 입력하지 않는다.

데이터와 암호화 키는 별도로 안전하게 보관한다. 컨테이너 삭제는 var 데이터를 삭제하지 않는다. 디스크 자체가 사라지는 무료 호스팅에 SQLite 파일을 두면 주문/보고서가 유실될 수 있다. 재시작 시 데이터가 보존되는지 검증하지 않은 서버를 판매용으로 사용하지 않는다.

## 이후 결정
공개 테스트 서버가 필요해지면 한국 접속 속도, 지속 저장소/DB, 비용 상한, 백업을 먼저 비교한다. 무료 요금제의 잠자기/저장소 제한을 확인한다. 키를 받기 위해 서버에 급히 가입하거나 결제를 활성화할 필요는 없다. 실제 운영은 OWNER_ACTION_REQUIRED.md의 차단 목록과 별도 승인을 따른다.

## 이번 환경 검증
- Docker Compose 설정 구문 검사 통과. 외부효과 disabled/local 강제, loopback 바인딩, 웹 healthcheck, 재시작 및 init 설정 추가.
- Docker 기반 Node 이미지 다운로드는 성공했지만 컨테이너에서 npm 레지스트리 접속이 실패하여 clean build 검증은 중단했다. 컨테이너 앱/워커 실행 및 영속성 테스트는 아직 통과로 표시하지 않는다. 기존 로컬 Next.js 빌드 통과와는 별개다.
- 가비아 베이직 구매 검토: 정확한 상품 URL/사양 미확인. Node.js 24 실행, 상시 프로세스와 별도 작업자, 지속 저장소, HTTPS/환경변수, 백업 지원 확인 전 구매 권장하지 않음. 일반 PHP/정적 웹호스팅과 Node 실행 서버를 혼동하지 않는다.
