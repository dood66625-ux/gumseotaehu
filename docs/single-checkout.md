# 단일 구매 화면과 무료 풀이 설명

구매 화면의 ‘한 권의 운명서’ 문구는 무료 풀이의 절대 위치 헤더 클래스를 더 이상 사용하지 않는다. 구매 전용 정적 배치로 제목과 겹침을 방지한다. 구매의 7개 화면·이전/다음·페이지 카운터·단계 상태는 제거했다.

한 URL에서 상품/가격·출생정보 요약·이메일 인증·필수 동의·결제를 진행한다. 인증 전에는 인증에 집중하고 인증 후 같은 화면에 동의/결제를 표시한다. 상세 항목·구매/환불 고지·체험 옵션은 펼쳐볼 수 있다. 필수 모두 동의는 다섯 개의 기존 필수 항목만 선택하며 선택 마케팅이나 카드 위젯의 자체 약관에는 적용하지 않는다. 개별 필수 항목 해제 시 전체 동의 표시도 해제된다. 필수 미동의 제출은 차단하고 닫힌 상세를 열어 확인할 수 있게 한다. 결제·인증·거래 원장·위젯 승인/중복방지·외부효과 활성화 설정은 바꾸지 않는다.

320×568 실제 앱의 기본 인증 전/후 화면 높이·추가 단계 없음·제목 비겹침, 필수 동의/선택 제외/개별 해제, 구매부터 PDF·재열람·문의·관리자 모의 환불과 읽기 타임아웃 복구를 검증했다. 390/1440 카드 위젯 모의 테스트에서는 별도 카드 약관·한 번 요청·가격/콜백 검증을 확인했다. 정적 합성 공개 체험 흐름도 통과했다. 상세 펼치기·키보드·글자 확대·외부 결제 위젯처럼 필요한 경우 스크롤을 차단하지 않는다. 실단말/실판매 인수를 대신하지 않는다.

사주 기둥에는 네 칸의 의미·날 기운·기존 기질 설명과 시각 미상 제외 안내를, 오행에는 실제 최다 개수(동률 포함)와 기존 기질을 바탕으로 한 쉬운 읽는 법을 추가했다. 개수로 강약·좋고 나쁨을 단정하지 않으며 추가 AI 호출을 하지 않는다.
