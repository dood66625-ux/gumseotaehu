# 계산 체계와 검증 한계

엔진 lunar-javascript **1.7.8, MIT**, npm 수정일 확인 2026-11-06. AI와 독립된 순수 계산을 저장한다. 계산 스키마는 `lib/astrology.ts`, UI/구매 연령 정책은 서비스 계층에서 따로 검사한다.

- 로컬 시험 입력 범위: 한국 출생, 1989년 이후, 실제 대상자 본인 만14세 이상. 출생국가를 사용자가 확인해야 한다. 해외/역사 DST/1988년 이전은 거부한다.
- 양/음력·윤달은 라이브러리. 존재하지 않는 윤달/날짜는 거부한다. 중국 달력 기반이므로 **한국 달력과 전 범위 일치 미검증**. 실제 판매 불가.
- 년·월주 절입 시각은 중국 표준시 라이브러리에 KST를 1시간 되돌려 비교. 일·시주는 KST 벽시각으로 산출. **절기 독립 관측자료 전체 대조는 미완료**.
- 일주 경계 00:00, 라이브러리 EightChar sect2. 23:30은 같은 일주, 다음 00:30은 다음 일주. 진태양시/경도 보정 없음.
- 시간 미상은 계산 내부에서 정오를 대표시각으로 사용하되 시주와 대운/시작값을 제거한다. **절입 날짜의 년·월주 역시 출생시각에 따라 달라질 수 있어 결과를 확정할 수 없다**. UI에도 이 한계를 고지한다. 실제 운영에서는 절입일 불확실한 후보군 또는 계산 보류 구현이 필요하다.
- 오행은 천간/지지 본기 단순 개수. 지장간은 별도 표기, 계절/통근 가중치가 아니며 신강·신약/용신·희신을 추론하지 않는다.
- 십성은 일간과 각 천간의 오행 생극/음양 관계. 합충은 지지 육합·충만 구현. 천간합·형·해는 아직 미제공.
- 대운은 선택된 전통 남/여 계산 구분과 라이브러리 sect2. 순역/시작시각/10년 구간은 전문가 검증 전 시험값. 성정체성 추론 없음. 성별구분 미선택·시간 미상이면 대운 전체 제외.
- 세운은 상품 대상 연도(기본2027) 입춘 기준 간지. 월운은 **양력 각월15일의 대표 명리월**이며 월 전체 동일 간지가 아니다. 정확한 절입 구간 표는 미구현.

120개 일주를 라이브러리와 별도 Gregorian→JDN 공식 `(JDN+49)%60`으로 대조했다. 양음력 잘 알려진 날짜 3개, 입춘 전후 1쌍, 자시 경계 및 미상 등을 테스트했다. 이것은 한국천문연구원 자료 수집·독립 전문가 검수에 해당하지 않으며 대운/모든 절입·윤달의 정확성 인증이 아니다. `test-report.md`와 운영자 목록 참조.
