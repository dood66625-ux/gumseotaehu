# 사주 계산 경계 검증 보강

2026-11-14. 실제 고객정보 없이 합성 입력과 공개 참고자료만 사용했다.

## 수정한 문제
기존 시간 미상 입력은 정오의 연주/월주를 사용했다. 같은 날 절입 전후로 연주 또는 월주가 달라질 수 있으므로, 일관된 값을 확정할 근거가 없었다.

- 시간 미상: 한국 시각 하루의 시작/끝과 1분 여유 구간을 대조하여 연주/월주가 변하면 입력을 거부한다. 임의 정오 값을 저장하지 않는다.
- 시간 있음: HH:mm 단위는 초를 알 수 없고 모델/자료의 반올림 차이도 있어 해당 분 전후 1분까지 절입 경계가 있으면 거부한다. 전문가 확인이 필요하다고 안내한다.
- 거부는 reading 저장/preview_ready 이벤트/주문 생성 이전에 수행한다. 입력을 고쳐 새 요청으로 다시 진행할 수 있다.
- KST→CST 변환을 한 함수로 모았다. 자정 일주 경계 정책(sect2)은 유지한다.
- 새 계산 rules=geumseo-0.3. 기존 저장 차트/운명서를 자동 재계산하거나 덮어쓰지 않는다.

## 참고자료와 독립 대조
한국천문연구원 2024년 달력자료 V1.0a(2023-04-25 22:44), 확인일 2026-11-14:
https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2024

원문은 이 자료가 공식 발표 자료가 아니며 공식 발표 월력요항을 별도 확인하라고 명시한다. 이 출처를 '공식 인증'으로 표시하지 않는다. tests/fixtures/kasi-2024.json에 검증에 쓰는 최소 날짜/시각 사실과 출처/버전만 기록했다. 출처의 월건을 사주 절입 월주와 동일하다고 가정하지 않는다.

- 음력 초하루→양력 날짜 12개 대조.
- 월주 전환 절기 12개: 라이브러리 시각을 CST에서 KST로 변환한 뒤 출처의 분 단위 값과 60초 이내 차이 확인. 초 단위 완전 일치 검증이 아니다.
- 절기마다 출처 시각 전후 5분에 월주가 바뀌는지, 시간 미상과 경계 분 입력을 거부하는지 검사.
- 대설처럼 CST 날짜와 KST 날짜가 다른 경계도 검사.
- 시간 미상이지만 하루 내 연주/월주가 일정한 사례는 시주/대운 없이 허용.

출처 날짜/시각 대조는 독립 참고자료 검사다. 같은 라이브러리를 이용한 전후 비교/거부 동작 검사는 내부 일관성 검사로 구별한다. 기존 JDN 일주 산술 대조도 유지한다.

## 미완료
전체 지원 연도/음력 윤달·한국과 중국 달력 차이/1989년 이전 시간대·DST/진태양시/대운 시작·순역/학파별 자시 정책은 독립 전문가 검수 완료 상태가 아니다. 현재 경계 보호는 라이브러리가 예측하는 절입 주변만 차단하며, 모델 오차가 여유 구간보다 크면 감지하지 못한다. 부정확한 예측이나 상용 출시 가능을 보장하지 않는다. 실제 판매 차단 유지.

## 검증 결과
타입 검사 및 전체 단위/통합 테스트 265개, Next.js 프로덕션 빌드, 모바일 Chromium/WebKit·데스크톱 Chromium E2E 24개 통과. UI 경계 오류와 재입력, 기존 모의 구매/PDF/재열람/환불 흐름을 확인했다. 실제 고객정보 외부 전송/실결제/실메일/운영 배포는 하지 않았다. 기존 고정 합성 체험판은 유지하고 이번 서버 계산 변경은 main 소스에만 반영한다.
