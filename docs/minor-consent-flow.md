# 이용 연령과 법정대리인 · 입력 간소화 후

무료 입력에는 구매자 연령 선택을 표시하지 않고 `unconfirmed`를 저장한다. 성인으로 자동 간주하지 않는다. 수집 전 본인·만14세 이상 및 개인정보 처리 동의를 받아 계산한다. 실제 대상자 태양력 생일 기준 만14세 미만은 저장 전 서버에서 거부한다. 타인/아동 대상자 경로는 지원하지 않는다.

유료 구매 직전에 이메일 인증과 별도의 `buyerAdult=true` 동의를 요구한다. 누락/false는 서버에서 거부한다. 기존 14–18세 선언 기록은 유지하며 결제 차단을 우회하지 못한다. 현재 본인 풀이만 지원하므로 성인 구매 확인과 본인 생년월일이 모순되는 경우도 서버에서 거부한다. 대상자 생일만으로 구매자가 성인이라고 자동 인정하지 않는다.

동의 기록에 성인 확인,정책 버전,시각,확인 출처(checkout-self-declaration)를 저장한다. 이는 자가신고이며 법적 본인확인·연령확인 인증 완료가 아니다. 운영 전 신뢰 가능한 본인확인 제공자·PG/법무 정책 검토가 필요하다. 보호자 동의 절차가 미완성이므로 미성년 유료 결제를 활성화하지 않는다.

guardianConsent=true를 임의 추가해도 기존 미성년 차단을 우회하지 못한다. 향후 법정대리인 확인·관계·동의 범위·버전·철회·보관 및 취소 절차를 검증하고 별도 승인 후 변경한다. 고객센터 guardian 유형과 법정 소비자 권리는 유지한다.
