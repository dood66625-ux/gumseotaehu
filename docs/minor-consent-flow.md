# 연령과 법정대리인
수집 전 연령 선택: under14 → 입력 화면 없음/API 거부,14–18 → 무료 허용/주문 API403,19+ → 이메일 인증·주문. 입력된 대상자 태양력 생일 기준 만14세 미만도 서비스 계층에서 거부. 대상자 본인만 허용하고 타인/아동 경로 미구현.

구매자 연령은 사주 대상자 생일에서 추론하지 않는다. 현 연령 선택은 자가신고이며 적법한 성인 확인/본인확인 완료를 뜻하지 않는다. 신뢰할 수 있는 확인 제공자·PG/법무 정책 검토는 출시 전 필수다.

guardianConsent=true를 임의 추가해도 우회 불가. 미성년 결제를 허용하는 feature flag 자체를 제공하지 않는다. 향후 법정대리인 본인·관계·동의 범위·시각·버전·철회 기록·최소수집/보관·취소 절차를 검증하고 별도 승인 후 서버를 변경해야 한다. 고객센터 guardian 유형으로 미성년자 계약 취소를 검토할 수 있으며 일반 환불 제한으로 거절하지 않는다.
