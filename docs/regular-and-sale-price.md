# 정상가·판매가 표시 · 2026-11-28 KST

사용자가 정상가는44,000원이며22,000원으로 판매한다고 확인하여 메인·무료 풀이 마지막·결제 상품 카드에 정상가 취소선과 판매가를 표시했다. 구매 진입과 실제 카드 결제 버튼 문구를“22,000원 할인 결제하기”로 맞췄다. 가상의 마감일·수량·기간은 추가하지 않았다.

표시용 정상가와 실제 결제 금액 상수를 구분한다. 주문 발행·토스 승인·기존 주문/환불 원장의 금액은 변경하지 않으며 현재 결제는22,000원이다. 과거33,000원 주문의 기존 처리 지원도 유지한다. 데모/테스트 결제 식별 문구는 유지한다.

검증: 상용 빌드·타입·비밀값 검사 통과. 아이폰 WebKit/안드로이드·PC Chromium6건에서320×568 화면의 정상가·판매가, 취소선, 구매 진입, 결제 화면 인증 전후 배치·헤더 겹침을 확인했다. 실제 결제·환불·AI·메일 공급자 호출은 없다.
